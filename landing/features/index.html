Feature List UI Styles

Reference pages showing different ways to present product features. Boilerplate content for visual comparison.

Apple-inspired

Icon Grid

Clean grid with SVG icons above short feature titles and descriptions. Minimal, spacious, high-end.

 Modern

Bento Grid

Asymmetric tiles of varying sizes. Large hero features mixed with smaller supporting ones.

 Classic

Feature Cards

Equal-sized cards with icon, title, and body text. Good for scanning many features.

 Simple

Icon List

Vertical list with left-aligned icons. Compact and scannable.

 Comparison

Comparison Table

Side-by-side feature comparison across plans or product tiers.

 Progressive

Accordion

Expandable rows. Keeps the page short while allowing deeper detail on demand.

 Apple-inspired

Side-by-Side Comparison

Two-column layout with matching icons and specs. Ideal for tier or model comparison.

 Narrative

Alternating Rows

Zig-zag image/text layout. Common on Mercury and other modern SaaS sites for sequential storytelling.

 Interactive

Tabbed Tour

Tabs that switch the featured visual and description. Compact way to cover multiple capabilities.

 Workflow

Numbered Steps

Ordered process view. Echoes Linear’s chapter style and classic “how it works” sections.

 Proof

Stats Grid

Large numbers as the focal point. Used by Stripe, Mercury, and others to prove scale quickly.

 Organic

Masonry Grid

Pinterest-style varying height cards for a more dynamic feel.
